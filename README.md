# Python Programming Repository

Welcome to the **Python Programming** repository! This project serves as a comprehensive collection of Python programs, exercises, and projects covering fundamental to advanced topics, including file handling, GUI applications using Tkinter, turtle graphics, and standalone scripts.

---

## 📁 Repository Structure

```text
Python_Pogramming/
│
├── File_Handeling/     # Scripts demonstrating reading, writing, and file operations
├── GUI/                # Desktop applications built using Tkinter
├── Practice/           # Problem-solving scripts and algorithm practice
├── Project/            # Modular Python projects and applications
├── qr_generator.py     # Standalone QR code generator script
└── README.md           # Project documentation

```

---

## 🚀 Key Topics & Features

### 1. 📄 File Handling in Python

Learn and explore how to manage files dynamically:

* Opening, reading, writing, and appending to files (`.txt`, `.csv`, etc.).
* File system management using the `os` and `shutil` modules.
* Exception handling during file I/O operations.

### 2. 🖥️ Graphical User Interfaces (Tkinter)

Interactive desktop applications created with Python's standard GUI library:

* Event-driven programming and custom layouts using frames, grids, and packs.
* Input forms, buttons, dialog boxes, and visual interface designs.

### 3. 🐢 Turtle Graphics Projects

Fun and visual projects built with the `turtle` graphics module:

* Drawing geometric patterns and shapes.
* Building classic interactive mini-games and dynamic visual art.

### 4. 🛠️ Python Utilities & Mini-Projects

Practical scripts for everyday tasks:

* **QR Code Generator (`qr_generator.py`)**: Utility script to generate custom QR codes instantly.
* **Practice Programs**: Core logic building, data structures, and algorithms.
